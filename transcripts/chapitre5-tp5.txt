VI) Les fonctions
1. L'assistant fonction
✔ Cliquez sur la cellule dans laquelle vous voulez entrer la fonction. ✔ Cliquer sur: ✔ Entrez les arguments nécessaires puis appuyez sur Entrée.
2. Catégories des fonctions

Fonction Définition Exemple

Exemple1: somme de données numériques
✔ Cliquez sur la cellule dans laquelle vous souhaitez voir apparaître le résultat et Cliquer sur fx: ✔ Sélectionnez «SOMME» et cliquez sur «OK» ✔ Sélectionnez la plage «B2:F2» et cliquez sur «OK»
Remarque :
Même étapes pour les fonctions : produit, max, min, moyenne et Nb
Exemple2: la somme des cellules qui contiennent des valeurs inferieurs à 10
✔ sélectionnez la cellule dans laquelle vous souhaitez voir apparaître le résultat et Cliquer sur fx: ✔ Sélectionnez «SOMME.SI» et cliquez sur «OK» ✔ dans la zone «plage» sélectionnez la plage «B2:F2», dans la zone «Critère» tapez «<10» ✔Cliquez sur «OK»
Remarque :
Même étapes pour la fonction NB.SI
Exemple3: Le Rang
✔ sélectionnez la cellule dans laquelle vous souhaitez voir apparaître le Rang et Cliquer sur fx: ✔ Sélectionnez «RANG» et cliquez sur «OK» ✔ dans la zone «Nombre» Sélectionnez le nombre dont vous voulez connaitre le rang, dans la zone «Référence» Sélectionnez la plage «B2:F2», dans la zone «Ordre» tapez «0» pour afficher le rang dans la liste triée par ordre décroissant ✔Cliquez sur «OK»
Exemple4: La fonction SI
✔ sélectionnez la cellule dans laquelle vous souhaitez voir apparaître le résultat et Cliquer sur fx: ✔ Sélectionnez «SI» et cliquez sur «OK» ✔ dans la zone «Test_logique» Taper (par exemple) «B2>=10», dans la zone Valeur_si_vrai tapez «Réussi», dans la zone «Valeur_si_faux» tapez «échoué» ✔Cliquez sur «OK»
