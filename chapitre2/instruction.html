IV. Les instructions de base

1. L’affectation

L’affectation consiste à donner une valeur à une variable. Elle est souvent représentée par une flèche orientée vers la gauche ←

Syntaxe Exemple
Variable ← valeur ou expression


 a ← 20
b ← a+10
nom ← "algo”

Exercice d’application:

Quelles seront les valeurs des variables A, B et C après exécution des instructions suivantes ?

Algorithme affectation
Variables
A, B, C : Entier
Début
A ← 5
B ← 3
C ← A + B
A ← A – B
B ← C – A
C ← B – A
Fin

Corrigé

A = 2
B = 6
C = 4

2. Instruction d'écriture

L’instruction d’écriture sert à afficher un message ou la valeur d’une variable à l’écran.

Syntaxe Exemple
écrire (variable)
écrire (" message")
écrire ("message", variable)
 écrire (x)
écrire (" Bonjour")
écrire ("La moyenne est: ", m)

Exercice d’application:

Écrire un algorithme qui permet d’afficher le message Bonjour.

Corrigé

Algorithme message
Début
écrire (" Bonjour")
Fin.

3. Instruction de la lecture

L’instruction de lecture permet de récupérer les données saisies par l’utilisateur

Syntaxe Exemple
lire (variable)
 lire (x)

!! Attention: La variable x doit être préalablement déclarée dans la partie déclaration de l’algorithme

Exercice d’application:

Écrire un algorithme qui demande à l'utilisateur son prénom, puis affiche la phrase : « Bonjour prénom »

Corrigé

Algorithme message
Variable
P : chaine de caractères
Début
écrire (" taper votre prénom")
Lire (p)
écrire (" Bonjour ", p)
Fin.
