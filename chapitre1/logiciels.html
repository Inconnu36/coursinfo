V- Types des logiciels

1. Logiciel de base

Un logiciel de base est un programme indispensable au bon fonctionnement d’un système informatique, il sert comme interface entre le matériel et l’utilisateur. Les principaux types de logiciels de base sont :

a) Systèmes d'exploitation (OS) :
Ensemble de programmes qui permettent le fonctionnement et l’utilisation des ressources matérielles et logicielles de l’ordinateur

Exemples :

- Windows (Microsoft)
- macOS (Apple)
- Linux (distributions libres comme Ubuntu, Fedora, Debian,….)
- iOS et Android (pour mobiles)

b) Les pilotes (drivers):
Ce sont des logiciels qui permettent au système d’exploitation de communiquer avec le matériel

c) Le BIOS / UEFI:
Logiciel stocké sur la carte mère, permet d’initialiser le matériel lors du démarrage de l’ordinateur avant de lancer l’OS.

2. Logiciel d'application

Un logiciel d’application est un programme informatique qui permet à l’utilisateur de réaliser une tâche spécifique, comme travail de bureau ou un travail personnel.

Exemples :

- Traitement de texte : Microsoft Word, WPS Office, Google Docsc...
- Tableur Microsoft Excel, LibreOffice Calc, Lotusc...
- Navigateur Web : Google Chrome, Microsoft Edg, Mozilla Firefoxc...
- Éditeur d’images Adobe Photoshop, Photo filtre, GIMPc...
- Applications mobiles WhatsApp, Instagram, ...
