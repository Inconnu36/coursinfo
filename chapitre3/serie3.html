exercice N°11║ Correction

Ecrire un Programme python et programme Python qui donne la mention selon la moyenne générale obtenue par un élève :
- Si 0 ≤ moyenne < 4 : très faible
- Si 4 ≤ moyenne < 8 : faible
- Si 8 ≤ moyenne < 10 : insuffisant
- Si 10 ≤ moyenne < 12 : Passable
- Si 12 ≤ moyenne < 14 : Assez bien
- Si 14 ≤ moyenne < 16 : Bien
- Si 16 ≤ moyenne < 18 : Très bien
- Si 18 ≤ moyenne < 20 : Excellent
