III. Les instructions de base

1. L’affectation

L’affectation consiste à donner une valeur à une variable à l’aide du symbole =

Syntaxe:

Variable = valeur ou expression

Exemple:

- x,y= 2,5 : Affectation parallèle (La valeur x sera 2 et de y sera 5)
- x+= 8 : Affectation augmentée : (x= x+8, si x est déjà référencé)
- x = b = z = 8 : Affectation multiple (Les trois variables x, y et z auront la même valeur 8)

!! Attention: le symbole = n’a pas le même sens ici que dans une égalité mathématique

2. Instruction d'écriture

L’instruction d’écriture sert à afficher un message ou la valeur d’une variable à l’écran.

Syntaxe Exemple
print (variable)
print (" message")
print ("message", variable)
 print (x)
print (" Bonjour")
print ("La moyenne est: ", m)

En Python, il existe une autre façon d’utiliser la fonction print() grâce aux f-strings (formatted string literals). Cette méthode permet d’insérer facilement des variables ou des expressions directement dans le texte.

Exemple:

print (f "la moyenne est {m} ")

Remarque:

- Pour ne pas aller à la ligne et continuer sur la même ligne lors du prochain print, on ajoute le paramètre end=" " :
print("la moyenne est", m, end=" ") ou print ( f "la moyenne est {m} ", end=" ")
- Pour effectuer un retour à la ligne dans un print() en utilisant le caractère spécial \n
print("Bonjour \n Tout le monde")

Exercice d’application:

Écrire un programme python qui permet d’afficher le message Bonjour.

Corrigé

print (" Bonjour")

3. Instruction de la lecture

La lecture est une instruction qui permet de lire les données saisies au clavier.

Syntaxe Exemple
variable = input()

 M = input()
M = input("tapez votre moyenne ")

!! Attention: la fonction input() renvoie toujours une chaîne de caractères.
Il faut donc utiliser la fonction int() ou float() pour convertir cette chaîne en entier ou en nombre réel
Exemple : M= int(input ("tapez votre moyenne "))

Exercice d’application:

Écrire un Programme python qui demande à l'utilisateur son prénom, puis affiche la phrase : « Bonjour prénom »

Corrigé

print (f" Bonjour {p}")
ou

a. pérateurs arithmétiques

Remarque:

- La fonction sqrt nécessite l'importation de la bibliothèque avec from math import sqrt.(voire: Les fonctions prédéfinies en Python)
-
- La même variable peut avoir différents types au cours de programme

Pour les chaînes de caractères, deux opérations sont possibles, l’addition et la multiplication
- L’addition (+) concatène (assemble) deux chaînes de caractères.
- La multiplication (*) entre un nombre entier et une chaîne de caractères duplique (répète) plusieurs fois une chaîne de caractères.

Symbole Exemple Résultat

Inférieur ou égal <= 9 <= 2 Faux
Supérieur > 9 > 2 Vrai
Supérieur ou égal >= 9 >= 2 Vrai

Symbole Exemple Résultat
