II. Les variables

Une variable est une zone de la mémoire de l’ordinateur dans laquelle une valeur est stockée.

1. Déclaration de variables

- En python, pas de déclaration de variables : une variable est créée lors de son initialisations

- L’identificateur (nom de la variable) est sensible à la casse : (par exemple : somme, Somme et SOMME ne sont pas identiques)

2. Types de variables

Le type d'une variable correspond à la nature de celle-ci. Les quatre types principaux dont nous aurons besoin sont :

✔ int: Ce type contient des nombres positifs ou négatifs, sans fractions ni décimales.

Exemple: 12, -2, 275

✔ float: Ce type contient des nombres à virgule flottante, représentés avec un point décimal.

Exemple: 0.225 , -12.45

✔ str: Chaîne de caractères délimitée par des guillemets simples (') ou doubles (") Exemple: "Bonjour", " mars2025, "271"

✔ bool: True ou False

Remarque:

- Vous remarquez aussi que Python reconnaît certains types de variable automatiquement (entier, réel).
- La même variable peut avoir différents types au cours de programme
