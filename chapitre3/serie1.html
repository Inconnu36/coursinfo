Série d'exercices N°1



exercice N°1║ Correction

Ecrire un Programme Python qui demande à l'utilisateur de saisir son nom et de lui afficher son nom avec un message de bienvenue !
exercice N°2║ Correction

Écrire un Programme Python permettant de saisir le nom et l'âge de l'utilisateur et de lui afficher "Bonjour ..., tu as ... ans." en remplaçant les ... par respectivement le nom et l'âge.
exercice N°3║ Correction

Ecrire un Programme Python qui calcule et affiche la somme et le produit de deux nombres réels
exercice N°4║ Correction

Ecrire un Programme Python qui calcule et affiche le périmètre d’un cercle (p=2*Pi*R)
exercice N°5║ Correction

Ecrire un Programme Python qui calcule et affiche la moyenne de 3 notes sachant que les coefficients de ces 3 notes sont respectivement 3 , 2 et 5
exercice N°6║ Correction

Ecrire un Programme Python qui lit le prix HT d’un article, le nombre d’articles et le taux de TVA, et qui fournit le prix total TTC correspondant. Faire en sorte que des libellés apparaissent clairement.
exercice N°7║ Correction

Etant données quatre nombres A, B, C et D représentant 4 chiffres entre 0 et 9. Ecrire un Programme Python qui retourne le nombre N = ABCD (exemple A=5, B=8, C=2 et D=3, N= 5823).
exercice N°8║ Correction

Connaissant le prix d’achat d’un produit, le frais de transport et son prix de vente. Ecrire un Programme Python qui affiche le bénéfice réalisé

exercice N°9║ Correction

Écrire un Programme Python qui demander à l'utilisateur de saisir les longueurs et largeurs d'un rectangle, afficher sa surface.
exercice N°10║ Correction

Écrire un Programme Python qui permet d’effectuer une permutation circulaire des valeurs de trois Variables x, y, z (la valeur de y dans x, la valeur de z dans y et la valeur de x dans z).
N B: L’affichage se fait après l’échange (Permutation)
exercice N°11║ Correction

Ecrire un Programme Python qui demande un nombre entier à l’utilisateur, puis affiche la valeur absolue de ce nombre
