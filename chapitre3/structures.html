V. Structures de contrôle de base

1. Structure sélective

La structure sélective permet d’exécuter un bloc d’instructions seulement si la condition est vérifiée (vraie).

Syntaxe Exemple 1 Exemple 2
if condition :
bloc d'instructions
 if x>0 :
print (" x est positif ")
if x>y :
max = x

Exercice d’application:

Écrire un Programme python qui demande à l'utilisateur de saisir une température. Si la température saisie est supérieure à 100, afficher « Température trop élevée ! ». Dans le cas contraire, l’algorithme ne fait rien.

Corrigé

T = int(input(" taper la température"))
if T>100 :
print (" Température trop élevée ! ")

2. Structure alternative

La structure alternative permet d’exécuter un bloc d’instructions si une condition est vraie, et un autre bloc si cette condition est fausse.

Syntaxe Exemple 1 Exemple 2
if condition :
bloc d'instructions 1
else :
bloc d'instructions 2
 if x>0 :
print (" x est positif ")
else :
print (" x est négatif ")
if x>y :
max = x
else:
max = y

Exercice d’application:

Écrire un Programme python qui permet de calculer la moyenne de deux notes saisies par l'utilisateur, puis affiche :

- «Réussi» si la moyenne est supérieure ou égale à 10,
- «Rattrapage» si la moyenne est strictement inférieure à 10 et supérieure ou égale à 8,
- «Échoué» dans tous les autres cas.

Corrigé

x=float(input(" taper la 1ère note"))
y=float(input(" taper la 2ème note"))
m = (x+y)/2
print(f" La moyenne est {m:.2f} ")
if m >= 10 :
print(" Réussi ")
elif m >= 8 :
print(" Rattrapage ")
else:
print(" échoué ")
