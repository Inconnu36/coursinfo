exercice N°1║ Correction

Ecrire un Programme python qui demande un nombre entier à l’utilisateur, puis calcule et affiche la racine carrée de ce nombre
exercice N°2║ Correction

Ecrire un Programme python qui demande un nombre à l’utilisateur, et l’informe ensuite si ce nombre est pair ou impair
exercice N°3║ Correction

Ecrire un Programme python qui demande un nombre à l’utilisateur, et l’informe ensuite si ce nombre est positif ou négatif (on laisse de côté le cas où le nombre vaut zéro)
exercice N°4║ Correction

Ecrire un Programme python qui demande trois nombres à l’utilisateur et l’informe ensuite s’ils sont rangés ou non dans l’ordre croissant consécutif.
exercice N°5║ Correction

Ecrire un Programme python qui lit le nom et les deux notes d’un élève, puis il affiche :
– Bonjour élève
– Votre moyenne est: moyenne
– Vous avez réussi si la moyenne est supérieure ou égale à 10
– Vous avez échoué si la moyenne est inférieure à 10
exercice N°6║ Correction

Ecrire un Programme python qui demande à l'utilisateur de saisir deux nombres entiers a et b et de lui afficher leur maximum
exercice N°7║ Correction

Ecrire un Programme python qui demande à l'utilisateur de saisir deux nombres entiers et de lui afficher leur minimum
exercice N°8║ Correction

Ecrire un Programme python qui demande à l'utilisateur de saisir son âge et de lui afficher le message
- « vous êtes Majeur ! » si l’âge tapé est supérieur ou égale à 18
- « vous êtes mineur ! » si l’âge tapé est inférieur à 18
exercice N°9║ Correction

Ecrire un Programme python qui demande deux entiers (x,y) à l’utilisateur et affiche :
- La somme de ces deux nombres : si x>y
- Le produit de ces deux nombres : dans le cas contraire
