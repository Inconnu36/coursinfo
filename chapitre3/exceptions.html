VI. Gestions des exceptions en Python

Lors de l'écriture d'un programme, nous rencontrons très souvent des erreurs.

✔ Erreur de syntaxe: Erreur due au non-respect de la structure (syntaxe) du langage

✔ Erreur d’exécution : Appelées exceptions, elles surviennent, par exemple, lorsqu'un fichier que nous essayons d'ouvrir n'existe pas (FileNotFoundError), ou lorsqu'un nombre est divisé par zéro (ZeroDivisionError)….

1. Gestion des exceptions

Pour gérer les exceptions et appeler du code lorsqu'une exception se produit, nous pouvons utiliser une instruction try/except.

✔ Le bloc try contient du code qui pourrait générer une exception.

✔ Si cette exception se produit, le code du bloc try s'arrête et celui du bloc except est exécuté.

✔ Si aucune erreur ne se produit, le code du bloc except ne s'exécute pas.

Syntaxe Exemple
try:
# Code qui peut provoquer une exception
except ExceptionType:
# Code exécuté en cas d'exception 		try :
z=3/0
except ZeroDivisionError:
print("Division par zéro impossible !")

Remarque:

Une instruction try peut comporter plusieurs blocs except afin de gérer différents types d'exceptions.

Exemple1

try :

- Si l'utilisateur entre autres chose qu’un nombre (par exemple du texte), une erreur ValueError sera levée et le message « Désolé, les valeurs saisies ne sont pas des nombres » sera affiché

- Si l’utilisateur entre zéro comme deuxième nombre, une division par zéro (ZeroDivisionError) sera levée et le message « Désolé, la division par zéro n'est pas permise » sera affiché

3. L’instruction raise

raise est une instruction utilisée pour forcer une exception (erreur) à se produire volontairement dans un programme.

Exemple3

try:
age = int(input("Entrez un nombre : "))
if age < 0 :
raise ValueError ("L'âge ne peut pas être négatif.")
elif age < 18:
print("Vous êtes mineur.")
else:
print("Vous êtes majeur.")
except ValueError as e:
print(f"Erreur : {e}")

- Si age est inférieur à 0, il lance une exception ValueError avec le « message L'âge ne peut pas être négatif »
